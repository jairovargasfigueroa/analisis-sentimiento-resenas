1 · Problema

¿Esta noticia parece falsa?

  • Circulan noticias falsas en español por medios digitales, Facebook y WhatsApp.
  • Verificar cada una a mano es lento.
  • Objetivo: una primera señal rápida: falsa o verdadera, con su probabilidad.
  • Y mostrar cómo se procesó el texto, paso a paso.

El modelo no verifica hechos: juzga cómo está escrito el texto.

Las dos versiones no tienen el mismo formato

  • Encabezados distintos: Category / CATEGORY, Topic / TOPICS.

Sin igualarlo, el modelo aprende de qué año es la noticia. Corregirlo bajó el F1 base de 0,796 a 0,786: ese punto era falso.

3 · Pipeline de NLP

Un solo Pipeline, igual al entrenar y al predecir

normalizar → tokenizar → stop words → lematizar → quitar tildes → TF-IDF → modelo

¡¡ALERTA!! La OMS confirmó que 3 niños murieron 😱 https://…

→ exclamacion alerta exclamacion oms confirmar num niño morir emoji

  • Exclamaciones y emojis se vuelven tokens: el tono sensacionalista es señal.
  • Se conservan las negaciones: «no hay vacuna» ≠ «hay vacuna».
  • Se serializa entero (.joblib): la API no reimplementa el preprocesamiento.

4 · La decisión que más cuesta explicar

Las tildes se quitan al final

PalabraLema (spaCy)
afirmóafirmar ✓
afirmo (sin tilde)afirmoir ✗
  • spaCy necesita las tildes → se lematiza antes de quitarlas.
  • Snowball (stemming) une palabras distintas: «murieron» y «muro» → mur.
  • Lema y stem se comparan con validación cruzada en el experimento E1 (diapositiva 8).

11 · Conclusiones

Una primera señal, no un verificador

  • Supera a la línea base por 44 puntos de F1 con dos modelos simples y explicables.
  • Aprende cómo está escrita una noticia, no si es verdad.
  • Los datos mandan: la fuente y las firmas filtradas habrían dado un modelo «perfecto» e inútil.
  • Se degrada con el tiempo (E3): habría que reentrenarlo con noticias nuevas.
  • Reproducible: python -m src.models.train da siempre los mismos números (SEED = 42).

Todo sale de params.yaml: cambiar una línea y reentrenar con --rapido tarda ~45 s.
